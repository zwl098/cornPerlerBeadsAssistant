## 0. 文档说明

本文档定义「拼豆助手」MVP 的产品定位、用户问题、功能范围、交互规则与验收标准。

**一句话定位：** 这不是拼豆图片查看器，而是拼豆过程中的「定位、数格、标记」工作台。

**核心卖点：** 不再数错格。

**体验目标：**

| 目标 | 含义 | 用户感知 |
| --- | --- | --- |
| 看得清 | 图纸可放大、网格清晰、当前位置明显 | 格子不再糊成一团 |
| 数得准 | 系统替用户计数、测距、记录连续选择 | 不用靠手指和记忆数格 |
| 找得到 | 随时知道行列、当前格、已完成区域 | 放大后也不会迷路 |

---

## 1. 产品定位

### 1.1 产品是什么

拼豆助手是一款面向拼豆玩家的 **图纸作业工具**。用户上传拼豆图纸后，可以在图纸上叠加网格、定位格子、按行列导航、连续数格、两点测距，并标记已完成进度。

它服务的是「看图摆豆」这一真实手工过程，而不是「看图欣赏」。

### 1.2 产品不是什么

MVP **明确不是**：

- 拼豆图片图库 / 社区
- 像素画编辑器 / 图纸生成器
- AI 识图或自动拆色工具
- 商城、支付、账号体系
- 社交内容平台

如果一个功能不能帮助用户「看得清、数得准、找得到」，就不进入 MVP。

### 1.3 要解决的核心问题

用户一边看手机图纸、一边在钉板上摆豆，会反复遇到：

1. 格子太小，看不清颜色和边界
2. 数格子容易多数、少数、跳格
3. 数到一半忘记数到哪里
4. 放大后迷失当前位置
5. 不知道当前是第几行、第几列
6. 摆完一部分后无法记录进度
7. 大图纸在手机上操作困难

这些问题的本质不是「图片不够大」，而是：

> 用户在物理世界摆豆时，需要一个不会丢位置、不会数错、可以断点续拼的数字辅助层。

### 1.4 价值主张

| 角色 | 价值 |
| --- | --- |
| 对用户 | 少数错、少返工、少迷路，大图纸也能一段一段拼完 |
| 对产品 | 成为拼豆作业过程中的默认工具，而不是偶尔打开的看图页 |
| 对后续 | 先把「作业工具」做深，再考虑图纸库、分享、AI 辅助 |

### 1.5 产品原则

| 编号 | 原则 | 落地要求 |
| --- | --- | --- |
| P1 | 任何时候用户都知道「我现在在哪」 | 始终可见：当前行列、当前格高亮、进度 |
| P2 | 任何时候用户都可以快速定位 | 支持缩放、拖动、点选格子、行列显示；后续可增强跳转 |
| P3 | 数格不容易数错 | 系统计数，不让用户心算；连续选择有明确起点/终点/格数 |
| P4 | 工具 UI 不遮挡图纸 | 主画布最大化；工具条贴边、可收起；浮层避开当前操作区 |
| P5 | 移动端优先 | 单手可操作；点击热区足够大；避免精细手势作为唯一路径 |

补充约束：

- **网格与图片绝对同步**：缩放、拖动后不得错位。
- **完成标记不破坏看色**：标记是轻量状态，不能盖住豆子原色。
- **本地优先**：进度保存在本机，刷新/重开可恢复。

## 2. 用户画像

### 2.1 主要用户

| 用户类型 | 特征 | 核心诉求 |
| --- | --- | --- |
| 拼豆爱好者 | 已有钉板、豆子、熨斗等工具，经常按网图制作 | 少数错、能记录进度、手机上好用 |
| 像素画拼豆玩家 | 图纸更大、颜色更多、耗时更长 | 精确定位、分段完成、可中断续做 |
| 手工爱好者 | 偶尔做一两次，熟练度不高 | 降低入门门槛，减少挫败感 |
| 网图制作者 | 从小红书、微博、Pinterest、Discord 等保存图纸 | 快速上传、立刻开始拼，不需要注册 |

### 2.2 典型人物

**人物 A：阿宁，26 岁，业余拼豆玩家**

- 晚上在书桌前拼 50×50 以上的图纸
- 左手拿豆子，右手点手机
- 最怕「数到第 20 格发现对不上」
- 一次做不完，第二天还想接着拼

**人物 B：小周，19 岁，学生**

- 用手机保存网上像素图纸
- 在宿舍床上或课桌前操作
- 经常放大看颜色，放大后找不到刚才那一块
- 需要明显的当前行/列提示

**人物 C：林姐，34 岁，亲子手工**

- 带孩子一起拼小型图纸
- 需要简单、不容易误触
- 希望能看到「还剩多少」

### 2.3 使用环境

| 维度 | 描述 |
| --- | --- |
| 设备 | 以手机为主，少量平板 / 电脑 |
| 姿态 | 图纸摊在桌上或钉板上，手机立着或拿在非惯用手 |
| 时长 | 单次 15 分钟到数小时；一个作品可能跨天 |
| 网络 | 上传后主要离线使用；不能依赖服务端 |
| 干扰 | 经常中断：倒豆子、对颜色、接电话、离开座位 |

### 2.4 用户目标分层

| 层级 | 目标 |
| --- | --- |
| 即时目标 | 看清当前格子，确认行列，数对一段距离 |
| 阶段目标 | 完成一行 / 一个色块 / 一个区域，并标记下来 |
| 作品目标 | 把整张图纸拼完，中途不丢失进度 |
| 情感目标 | 有掌控感，减少返工带来的烦躁 |

## 3. 用户场景

### 3.1 主场景：边看图边摆豆

阿宁打开拼豆助手，上传一张已保存的图纸，调整网格使每格对应一颗豆。她放大右上角区域，点中一格，系统显示「第 8 行 × 第 12 列」，当前行和当前列被辅助高亮。她按这个位置在钉板上找到对应格子，开始摆豆。

### 3.2 场景：连续数格

阿宁要在同一行连续摆 4 颗同色豆。她打开数格模式，点起点（8, 12），再点终点（8, 15）。系统显示「共 4 格」，并高亮这段路径。她按系统结果摆豆，不再自己倒数。

### 3.3 场景：确认色块大小

小周看到一块矩形色区，不确定宽高。他进入两点测距，点左上和右下两个角，系统给出横向距离、纵向距离、矩形宽高。他据此准备豆子数量。

### 3.4 场景：中断后续拼

林姐拼完左上 10 行后要去做饭。她把这些格子标为完成，关掉页面。第二天打开，图纸、网格、完成标记、上次当前格都还在，她从「下一未完成格」附近继续。

### 3.5 场景：放大后找回位置

小周把图放得很大看颜色，滑着滑着不知道自己在哪。他看顶部坐标「第 36 行 × 第 8 列」，同时看到十字辅助高亮，立刻知道自己在图纸左下方，把图拖回目标区。

### 3.6 场景：修正误标

阿宁不小心把未完成的格子标成完成。她点一次撤销，或再次点该格取消标记，图纸恢复原状。

### 3.7 非目标场景（MVP 不做）

- 在社区里搜图纸、点赞、评论
- 用 AI 把照片转成拼豆图纸
- 登录多设备云同步
- 购买豆子或图纸

## 4. 用户流程

### 4.1 主流程

```text
打开产品
  → 上传 / 选择已有图纸
  → 进入工作台
  → 校准网格（列数 / 行数 / 对齐）
  → 浏览图纸（缩放、拖动）
  → 点选格子，确认当前位置
  → 数格 或 测距 或 直接摆豆
  → 标记已完成格子
  → 查看进度
  → 离开（自动本地保存）
  → 再次打开，恢复进度，继续
```

### 4.2 首次使用流程

```text
落地页 / 工作台空态
  → 选择图片（相册 / 文件）
  → 读取成功，进入工作台
  → 引导 3 步（可跳过）：
      1. 设置列数与行数，让网格对上豆子
      2. 点一个格子，看行列和高亮
      3. 标记一格完成，看进度变化
  → 开始正式使用
```

首次引导必须短。目标是让用户 30 秒内完成「上传 → 对网格 → 点到第一格」。

### 4.3 回访流程

```text
打开产品
  → 自动恢复最近一份图纸与进度
  → 如有多份本地作品，展示「继续上次」和「作品列表」
  → 进入工作台，定位到上次当前格附近
```

### 4.4 工作台循环（核心回路）

用户在工作台中反复执行：

```text
定位（点格 / 拖动 / 缩放）
  → 确认（行列 + 十字高亮）
  → 辅助（数格 / 测距）
  → 执行（在真实钉板上摆豆）
  → 记录（标记完成）
  → 再定位到下一处
```

产品设计必须保证这个回路中，每一步都少于一次「想不起来自己在哪」。

### 4.5 关键决策点

| 决策点 | 用户在想什么 | 产品应给出的答案 |
| --- | --- | --- |
| 网格对不齐 | 这格是不是一颗豆？ | 明确的行列设置和预览对齐 |
| 点错格子 | 我点到哪了？ | 立刻高亮 + 坐标 |
| 要数一段 | 从这到那几格？ | 数格模式给出格数 |
| 要估一块 | 这块有多宽多高？ | 两点测距给出宽高 |
| 要停手 | 做了多少？下次从哪开始？ | 完成标记 + 进度 + 本地保存 |

## 5. 信息架构

### 5.1 全局结构

```text
拼豆助手
├── 落地 / 入口
│   ├── 上传新图纸
│   └── 继续已有作品
├── 作品列表（本地）
│   ├── 最近作品
│   ├── 打开
│   └── 删除
└── 图纸工作台（核心）
    ├── 画布层
    │   ├── 图纸图片
    │   ├── 网格
    │   ├── 当前格 / 行 / 列高亮
    │   ├── 数格路径
    │   ├── 测距矩形
    │   └── 完成标记
    ├── 状态层（不挡图）
    │   ├── 当前行列
    │   ├── 当前模式
    │   └── 完成进度
    ├── 工具层
    │   ├── 选择
    │   ├── 数格
    │   ├── 测距
    │   ├── 标记完成
    │   ├── 撤销 / 重做
    │   └── 更多
    └── 设置层
        ├── 网格设置
        ├── 显示开关
        └── 作品信息
```

### 5.2 对象模型

| 对象 | 说明 |
| --- | --- |
| 作品 Project | 一份本地作业：图片、网格、进度、操作历史 |
| 图纸 Image | 用户上传的图片文件或本地副本 |
| 网格 Grid | 列数、行数、相对图片的对齐偏移与边距 |
| 格子 Cell | 用 `(row, col)` 标识，1-based 展示 |
| 当前格 Focus | 当前选中的唯一格子 |
| 数格会话 CountSession | 起点、终点、路径、格数 |
| 测距会话 MeasureSession | 两点、横向/纵向距离、宽高 |
| 完成集 CompletedSet | 已完成格子集合 |
| 历史 History | 可撤销/重做的命令栈 |

### 5.3 模式

工作台同一时间只有一个主模式：

| 模式 | 用途 | 点击格子的含义 |
| --- | --- | --- |
| 选择模式 | 定位当前格 | 设置 Focus |
| 数格模式 | 连续计数 | 设置起点 / 终点，或追加路径 |
| 测距模式 | 两点测距 | 设置点 A / 点 B |
| 标记模式 | 快速刷完成态 | 切换格子完成 / 未完成 |

选择模式是默认模式。数格、测距、标记都是「进入后使用、用完可退回」。

### 5.4 导航原则

- 只有两级：入口 / 列表 → 工作台。
- 工作台内用底部工具切换模式，不用多级页面打断作业。
- 设置用底部抽屉或侧滑面板，不跳走。
- 返回列表前自动保存。

## 6. 页面结构

### 6.1 页面清单

| 页面 | 是否 MVP | 说明 |
| --- | --- | --- |
| 入口页 | 是 | 上传、继续上次、进入列表 |
| 作品列表页 | 是 | 本地作品管理 |
| 图纸工作台 | 是 | 核心作业页 |
| 网格校准面板 | 是 | 工作台内面板，不算独立页 |
| 显示设置面板 | 是 | 网格开关、高亮强度等 |
| 引导浮层 | 是 | 首次 3 步，可跳过 |
| 登录 / 社区 / 商城 | 否 | 明确不做 |

### 6.2 入口页

**目标：** 3 秒内开始工作。

模块：

1. 产品名与一句卖点：「不再数错格」
2. 主按钮：上传图纸
3. 次按钮：继续上次（无历史则隐藏）
4. 文字入口：我的作品

空态文案应说明：图片只保存在本机，不上传到服务器。

### 6.3 作品列表页

每条作品展示：

- 缩略图
- 名称（默认为文件名，可改）
- 网格尺寸，如 `48 × 48`
- 完成进度，如 `128 / 2304 · 5.6%`
- 最近打开时间

操作：打开、重命名、删除。删除需二次确认。

### 6.4 图纸工作台（核心页）

采用「画布全屏 + 边缘工具」结构。

```text
┌--------------------------------------┐
│ 顶栏：返回 │ 作品名 │ 进度  12%      │
│ 状态条：第 8 行 × 第 12 列 │ 选择    │
├--------------------------------------┤
│                                      │
│              图纸画布                 │
│         （图片 + 网格 + 高亮）         │
│                                      │
│     右侧/边缘：行号（可选显示）        │
│                                      │
├--------------------------------------┤
│ 底栏：选择 │ 数格 │ 测距 │ 完成 │ ··· │
└--------------------------------------┘
```

#### 6.4.1 顶栏

- 返回作品列表
- 作品名（可点开重命名）
- 完成进度：百分比 + 已完成/总格数
- 更多：网格设置、显示设置、导出当前视图（后续）、删除

顶栏高度尽量压缩。进度是「我做了多少」的全局锚点，必须常驻。

#### 6.4.2 状态条

常驻显示：

- 当前坐标：`第 8 行 × 第 12 列`
- 当前模式：选择 / 数格 / 测距 / 标记
- 模式结果（按模式切换）：
  - 数格：`起点 8×12 → 终点 8×15 · 共 4 格`
  - 测距：`横 4 · 纵 3 · 区域 4×3`
  - 未选中：`点一下格子，开始定位`

状态条可半透明，贴在画布顶部内侧，但不覆盖画布中心主体。

#### 6.4.3 画布

- 占屏幕最大面积
- 支持双指缩放、单指拖动；桌面支持滚轮缩放、拖拽
- 网格、高亮、标记全部与图片同一坐标系统
- 行号 / 列号刻度：在可视区域边缘显示当前附近的编号，随拖动更新

#### 6.4.4 底栏工具

移动端固定底部，预留安全区。

| 按钮 | 功能 |
| --- | --- |
| 选择 | 回到选择模式 |
| 数格 | 进入数格模式 |
| 测距 | 进入两点测距 |
| 完成 | 进入标记模式，或把当前格标为完成 |
| 撤销 | Undo |
| 重做 | Redo，可收入「更多」 |
| 更多 | 网格、显示、适应屏幕、定位到当前格 |

工具栏不可挡住图纸主体。必要时支持「轻点画布空白手势不收工具、上滑轻微隐藏/下滑唤出」—— MVP 以常驻底栏为准，高度控制在不抢画布。

#### 6.4.5 网格校准面板

字段：

- 列数（必填，整数 ≥ 1）
- 行数（必填，整数 ≥ 1）
- 锁定宽高比（可选）：改一维时按图片比例推另一维
- 网格边距 / 对齐微调（四边 inset 或整体偏移）
- 网格显示开关
- 网格线粗细 / 透明度

预览：调整时画布实时更新。提供「常见尺寸」快捷项，如 29×29、50×50，但不替代自定义。

校准是高风险操作：修改行列会改变格子坐标系。若已有完成标记，需提示「格子会重新映射，完成标记可能错位」，并提供确认。MVP 建议：改网格尺寸时清空完成标记和历史，或按比例无法可靠映射时直接清空并明确告知。

**MVP 决策：** 修改行数或列数时，清空完成标记、数格/测距会话和操作历史，保留图片；弹窗说明原因。仅改边距/偏移时保留标记。

### 6.5 桌面适配

- 画布仍是主体
- 工具栏可放到左侧或顶部，不必模仿 App 底栏
- 悬停格子可预览坐标，点击仍是主操作
- 快捷键见 8.10

## 7. 功能优先级

### 7.1 P0（MVP 必须有）

| 功能 | 用户价值 | 不做的后果 |
| --- | --- | --- |
| 上传图片 | 开始作业 | 产品无法使用 |
| 图片预览 | 看见图纸 | 无法对照摆豆 |
| 网格 | 建立「一格一豆」坐标系 | 无法定位和计数 |
| 缩放 | 看得清 | 小格不可用 |
| 拖动 | 找得到 | 放大后无法巡视 |
| 点击格子 | 选中位置 | 无法定位 |
| 当前格高亮 | 我在哪 | 点了也看不清 |
| 当前行高亮 | 横向不迷路 | 容易看串行 |
| 当前列高亮 | 纵向不迷路 | 容易看串列 |
| 行列坐标 | 给出明确数字位置 | 只能靠感觉 |
| 数格模式 | 数得准 | 仍靠人工数 |
| 两点测距 | 快速估块 | 大色块仍易数错 |
| 完成标记 | 记录进度 | 无法断点续拼 |
| Undo / Redo | 允许试错 | 误标代价过高 |
| 完成进度 | 看到还剩多少 | 缺少完成感与节奏 |
| 本地保存 | 跨会话继续 | 一关页面就白做 |

### 7.2 P1（MVP 后立刻做）

| 功能 | 说明 |
| --- | --- |
| 跳转到指定行列 | 输入行、列，画布定位过去 |
| 定位到当前格 / 下一未完成格 | 一键找回 |
| 按行标记 / 按矩形标记 | 加速完成记录 |
| 网格自动估算 | 根据图片尺寸给建议行列 |
| 多作品管理增强 | 复制作品、封面、排序 |
| 导出进度图 | 带标记的图纸，便于备份到相册 |
| 颜色滤镜 / 对比度 | 让浅色格子更好辨认 |
| 防误触锁定 | 锁定缩放或锁定标记 |

### 7.3 P2（中期）

| 功能 | 说明 |
| --- | --- |
| 色块识别辅助 | 点击后提示相近连续同色区域（规则算法，非重 AI） |
| 分色清单 | 统计图纸大概用色占比（需调色板或抽样） |
| 图纸裁切 | 去掉白边后再铺网格 |
| 暗色工作台 | 夜间拼豆减少刺眼 |
| 左手模式 | 工具栏镜像 |
| 网页分享只读进度 | 仍可不登录，用本地导出文件 |

### 7.4 明确不做（本阶段）

- 登录 / 注册 / 账号
- 社区、关注、评论、点赞
- AI 生成图纸、AI 识别豆子品牌
- 商城、支付、广告
- 服务端数据库与云同步
- 多人协作

### 7.5 优先级判断标准

只问三句话：

1. 有助于「看得清」吗？
2. 有助于「数得准」吗？
3. 有助于「找得到」吗？

三个都不是，就放到后续或放弃。

## 8. 核心交互

### 8.1 坐标系与网格

#### 规则

- 展示坐标从 **第 1 行、第 1 列** 开始，左上为原点。
- 每个格子对应图片上的一个矩形区域。
- 格子计算必须基于「图片本地坐标」，再映射到屏幕。禁止用「屏幕像素直接画独立网格」。
- 缩放、拖动、旋转（MVP 不开放旋转）时，图片、网格、高亮、标记使用同一变换矩阵。

#### 网格生成

```text
cellWidth  = (imageWidth  - insetLeft - insetRight)  / colCount
cellHeight = (imageHeight - insetTop  - insetBottom) / rowCount

cell(row, col) = {
  x: insetLeft + (col - 1) * cellWidth,
  y: insetTop  + (row - 1) * cellHeight,
  w: cellWidth,
  h: cellHeight
}
```

点击命中：将屏幕点逆变换到图片坐标，再计算 `col`、`row`。点在 inset 外或图外则不选中。

#### 对齐要求（验收级）

- 放大到单格边长 ≥ 40px 时，网格线与豆子边界目视误差不超过 1 像素级错位感。
- 连续缩放、拖动 30 秒后，网格仍不得出现漂移。
- 避免在缩放过程中用整数网格重绘造成抖动；优先变换整层。

### 8.2 缩放与拖动

| 操作 | 移动端 | 桌面 |
| --- | --- | --- |
| 缩放 | 双指捏合 | 滚轮 / 触控板 |
| 拖动 | 单指拖动 | 按住拖动 |
| 适应屏幕 | 双击空白或点「适应」 | 双击空白或按钮 |
| 定位当前格 | 点「定位」将当前格居中 | 同左 |

约束：

- 最小缩放：整图可见。
- 最大缩放：单格至少能被轻松点中。建议单格屏幕边长上限约 80–120px，避免无限放大失真。
- 缩放锚点：以手势中心为锚，而不是画布左上角。
- 拖动有边界阻尼，不能把图纸拖丢。
- **缩放不得改变当前选中格。**

### 8.3 当前格、当前行、当前列

用户在选择模式下点击一格后：

1. 该格成为当前格，使用最强高亮（描边 + 轻透明填充）。
2. 当前行使用弱高亮（横向色带）。
3. 当前列使用弱高亮（纵向色带）。
4. 状态条更新为：`第 {row} 行 × 第 {col} 列`。
5. 边缘刻度中，当前行列号加重显示。

视觉层级：

| 层级 | 元素 | 强度 |
| --- | --- | --- |
| 1 | 当前格 | 最强，必须一眼看到 |
| 2 | 数格路径 / 测距矩形 | 强，但弱于当前格描边 |
| 3 | 当前行 / 当前列 | 中，辅助定位 |
| 4 | 完成标记 | 弱，不抢色 |
| 5 | 网格线 | 最弱，只起分割 |

高亮必须「看见位置，但不改色」。禁止用实心不透明色块盖住豆子颜色。

再次点击当前格：保持选中，不取消。取消选中不是高频需求；如需取消，走「清除选中」入口，避免误触丢失位置。

### 8.4 数格模式

**目标：** 把「心算连续格子」变成「点两点得出格数」。

#### 进入 / 退出

- 点底栏「数格」进入，状态条标明数格模式。
- 再点「数格」或点「选择」退出。退出可保留上次结果展示，直到下一次开始新的数格。

#### 选择规则（MVP）

采用 **两点直线数格**，降低复杂度：

1. 第一次点击：设为起点，高亮该格。
2. 第二次点击：设为终点。
3. 若起点与终点同行：路径为该行闭区间所有格。
4. 若起点与终点同列：路径为该列闭区间所有格。
5. 若既不同行也不同列：不连斜线。提示「请选择同一行或同一列」，终点不生效，或改为自动进入测距建议。

**MVP 决策：** 非同行同列时，轻提示「数格只支持同一行或同一列，测距可以量矩形」，并保持起点，等待用户重新点终点。

#### 计数规则

格数按闭区间计算：

- 同行：`count = |col2 - col1| + 1`
- 同列：`count = |row2 - row1| + 1`

示例：`(8,12)` 到 `(8,15)` → 共 4 格。

#### 展示

- 路径上所有格轻高亮
- 起点、终点有不同角标：起 / 终
- 状态条：`第 8 行，第 12 列 → 第 8 行，第 15 列 · 共 4 格`
- 可在路径中点显示数字 `4`

#### 重新数

- 已有起点和终点后再点第三格：视为新的起点，清空旧路径。
- 提供「清除本次数格」按钮。

数格本身不自动标记完成。用户确认摆完后，可一键「将这段标为完成」（P0 建议有，成本低、闭环强）。

**P0 增加：** 数格结果出现后，状态条提供按钮「标记这 {n} 格完成」。该操作进入撤销栈。

### 8.5 两点测距

**目标：** 快速知道两格之间的跨度和矩形大小。

#### 规则

1. 第一次点击：点 A
2. 第二次点击：点 B
3. 计算：

| 指标 | 公式 | 含义 |
| --- | --- | --- |
| 横向距离 | `|colB - colA|` | 两格之间隔了多少列（不含自身差值） |
| 纵向距离 | `|rowB - rowA|` | 两格之间隔了多少行 |
| 矩形宽度 | `|colB - colA| + 1` | 含两端的列数 |
| 矩形高度 | `|rowB - rowA| + 1` | 含两端的行数 |
| 矩形格数 | 宽 × 高 | 这块一共多少格 |

说明文案必须让用户看懂「距离」和「占格」的差别。界面上优先展示对摆豆更有用的 **宽 × 高**，距离作为次要信息。

推荐展示：

```text
从 第 8 行 × 第 12 列
到 第 11 行 × 第 16 列
区域 5 × 4（20 格）
间隔 横 4 · 纵 3
```

#### 展示

- 点 A、点 B 高亮
- 以两点为对角画出矩形虚线框
- 不强制要求同行同列

第三次点击：作为新的点 A，重新开始。

测距不自动标记完成。可提供「标记此区域完成」（P0 建议有）。

### 8.6 完成标记

#### 行为

- 标记模式下点击未完成格 → 标记完成
- 再点已完成格 → 取消完成
- 选择模式下，可对当前格使用底栏「完成」切换当前格状态
- 数格 / 测距后支持把路径或矩形批量标记

#### 视觉

- 不遮挡原色
- 使用轻量记号：角标勾、细斜线、或格内小圆点
- 已完成格仍可被选中、高亮、数格
- 完成态与当前格同时存在时，当前格视觉优先

#### 撤销

标记、取消标记、批量标记都必须进入 Undo / Redo 栈。

### 8.7 Undo / Redo

可撤销操作：

- 单格完成 / 取消
- 批量完成 / 取消
- 清除全部完成（如有该入口）

不可撤销或单独处理：

- 缩放、拖动：不进栈
- 切换当前格：不进栈
- 数格 / 测距的点选：不进栈，因为那是临时会话
- 修改网格行列：MVP 会清空标记，该清空作为一次不可细粒度恢复的操作；可用「关闭面板取消」避免误改

栈深度：至少 50 步。超出丢最旧记录。

切换作品时，每个作品独立历史。

### 8.8 完成进度

```text
total = rowCount * colCount
done  = completedCells.size
percent = floor(done / total * 1000) / 10   // 一位小数，total 为 0 则 0
```

展示：`128 / 2304` 与 `5.6%`

进度只统计完成标记，不把「当前选中」算进去。

### 8.9 本地保存

#### 保存内容

- 图片（本地文件副本或 IndexedDB / 文件系统句柄允许范围内的持久副本）
- 作品名
- 网格参数：行列、inset
- 完成格子集合
- 当前格
- 上次视口（缩放、偏移）
- 更新时间

#### 保存时机

- 标记变化后防抖保存（建议 300–500ms）
- 网格设置确认时立即保存
- 页面隐藏 / 关闭前尽量保存（`visibilitychange` / `pagehide`）
- 切换作品前保存

#### 恢复

再次打开自动恢复最近作品。用户应感觉「上次停在哪，现在还在哪」。

MVP 不做账号，因此要在入口和设置中写清：清除浏览器数据会导致进度丢失。

### 8.10 桌面快捷键（P0 可用则做）

| 按键 | 行为 |
| --- | --- |
| `Esc` | 回到选择模式 / 关闭面板 |
| `Z` / `Ctrl+Z` | 撤销 |
| `Shift+Ctrl+Z` / `Ctrl+Y` | 重做 |
| `C` | 数格模式 |
| `M` | 测距模式 |
| `X` / `Space` | 切换当前格完成态 |
| 方向键 | 移动当前格 |
| `+` `-` | 缩放 |

移动端不依赖快捷键。

### 8.11 方向键与「找得到」

方向键或后续「邻格按钮」每次移动 1 格，并保证：

- 当前格若离开视口，画布自动轻量跟随，把当前格保持在可视区内。
- 这是原则 P1 / P2 的关键实现，建议 MVP 在桌面做方向键，移动端在「更多」里提供上/下/左/右轻移，避免挡图的常驻 D-Pad。移动端轻移可用底部工具长按「选择」弹出临时方向垫，或滑动状态条。  
- **MVP 最小集：** 桌面方向键必做；移动端提供「定位到当前格」。邻格步进作为 P0 增强，若排期紧可放到 P1，但会削弱「找得到」。

**P0 决策：** 移动端在状态条右侧放一个「回中」按钮，把当前格滚到屏幕中央。邻格步进放入 P1。

### 8.12 工具不挡图的具体规则

- 主操作发生在画布中心 70% 区域，工具只占边缘。
- 弹层默认从底部出来，高度不超过半屏；校准网格因为要对照图纸，面板应可半高拖拽，露出足够画布。
- 高亮、标记、网格线透明度可在显示设置中调节。
- 禁止大型居中 Modal 作为常用反馈。数格结果用状态条，不用弹窗。

## 9. 异常场景

| 场景 | 处理 |
| --- | --- |
| 未选择图片就进入工作台 | 不允许；停留入口，引导上传 |
| 文件不是图片 | 提示「请选择图片文件」，保持原状态 |
| 图片过大导致内存压力 | 超过上限（建议长边 8000px 或文件 20MB，实施时按设备能力调整）时提示压缩或拒绝，说明原因 |
| 图片过小 / 模糊 | 允许上传，但在校准阶段提示「图纸不够清晰，网格可能不好对」 |
| 行列输入非法 | 拒绝 0、负数、小数、空值；超过上限（建议 300，可配置）时提示可能卡顿 |
| 点击图片外 / 边距区 | 不改变当前格；可轻震动或无反馈 |
| 数格两点不同行也不同列 | 提示改选同行/同列，或去用测距 |
| 测距只点了一点 | 状态条显示「再点一个格子」 |
| 撤销到头 / 重做到头 | 按钮禁用，不报错 |
| 修改行列导致坐标失效 | 确认弹窗；确认后清空标记与历史 |
| 本地保存失败 | Toast：进度暂未能保存，建议不要清浏览器数据；下次操作再重试 |
| 本地数据损坏 | 尝试只恢复图片；失败则提示作品损坏，保留删除入口 |
| 刷新页面 | 从本地恢复，视口和当前格尽量还原 |
| 多标签打开同一作品 | MVP 不做实时同步；后写入覆盖先写入。可在打开时读最新 |
| 浏览器无存储能力 | 允许当次使用，强提示「关闭后进度无法保留」 |
| 误删作品 | 删除前确认；MVP 不做回收站 |
| 网格完全对不齐 | 提供 inset 微调；仍对不齐时提示先裁切（P2）或检查图纸是否含额外边框 |
| 大图纸卡顿 | 网格在小缩放级别可降采样绘制（合并线），但命中计算仍按精确格子；保证不同步错位 |
| 横竖屏切换 | 保持当前格与缩放中心，重新适配工具栏安全区 |
| 手势冲突（滚动页面 vs 拖动画布） | 工作台锁住页面滚动，仅画布内缩放拖动 |

所有错误提示用一句人话 + 下一步动作，不抛技术词。

## 10. MVP 范围

### 10.1 目标

用一个可在手机浏览器使用的 Web / H5 工具，验证：

> 用户是否愿意用「网格 + 定位 + 数格 + 标记」来完成一张真实拼豆图纸。

成功不看注册数，只看：用户能不能把一张图从上传用到标记完成。

### 10.2 做

- 入口：上传、继续上次、本地作品列表
- 工作台：预览、网格、缩放、拖动、点格
- 定位：当前格 / 行 / 列高亮、行列坐标、回中
- 辅助：数格模式、两点测距、路径/区域一键标记完成
- 进度：完成标记、进度数字、Undo / Redo
- 数据：本地保存与恢复
- 设置：行列、边距微调、网格显示、引导

### 10.3 不做

- 账号与云端
- 社区与社交
- AI
- 商城支付
- 复杂图像编辑
- 自动识别豆子品牌色号
- 原生 App 包（可先 PWA 化，但不作为 MVP 必达）

### 10.4 MVP 验收标准

#### 功能验收

1. 用户能从手机相册上传一张拼豆图并看到预览。
2. 用户能设置行列，网格与图片在缩放、拖动后保持对齐。
3. 点击格子后，当前格、当前行、当前列同时可见，状态条显示「第 X 行 × 第 Y 列」。
4. 数格模式下，同行或同列两点给出正确闭区间格数；示例 `(8,12)` 到 `(8,15)` 为 4。
5. 测距模式给出横向间隔、纵向间隔、矩形宽高和总格数。
6. 完成标记不遮挡原色，可取消，可撤销 / 重做。
7. 进度随标记正确变化。
8. 刷新或关闭重开后，图片、网格、标记、当前格、视口可恢复。
9. 工具栏在 iPhone 安全区和常见安卓机上不遮挡核心图纸区到无法操作。
10. 未登录可用全部 P0 功能。

#### 体验验收

- 新用户 1 分钟内完成：上传 → 设网格 → 点到第一格。
- 任何常规状态下，用户不用猜测自己在第几行第几列。
- 放大后按「回中」能回到当前格。
- 数格结果出现在状态条，不打断画布。

#### 非功能（MVP 下限）

| 项 | 要求 |
| --- | --- |
| 设备 | iOS Safari、Android Chrome 近两个版本；桌面 Chrome |
| 性能 | 100×100 网格缩放手感可接受，点击命中无可见延迟 |
| 离线 | 已打开的作品在无网下可继续标记（图片已本地化后） |
| 隐私 | 图片与进度默认不离开本机 |
| 无障碍 | 坐标与进度有文字，不只靠颜色 |

### 10.5 成功指标（上线后看）

因无账号，指标以本地埋点或匿名统计为准，也可先手工观察。

| 指标 | 定义 | MVP 期望 |
| --- | --- | --- |
| 激活完成率 | 上传并成功点选至少 1 格 | ≥ 60% |
| 网格校准完成率 | 上传后完成行列设置 | ≥ 70% |
| 数格使用率 | 产生至少 1 次有效数格 | ≥ 30% |
| 回访续拼率 | 第二次打开同一作品并新增标记 | ≥ 25% |
| 完成标记深度 | 单作品标记格子数中位数 | 观察，用于判断是否真在拼 |

定性成功：用户反馈从「看图工具」变成「我拼豆时开着它」。

### 10.6 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 网格难以对齐含白边的网图 | 定位全错 | inset 微调；后续做裁切和自动估行列 |
| 大图性能差 | 手机发烫、卡顿 | 分层绘制、缩放降载、限制尺寸 |
| 本地存储被清 | 进度丢失，信任崩塌 | 明确提示；P1 做导出备份 |
| 被理解成看图网站 | 核心价值没传出去 | 首屏和引导强调数格与定位 |
| 点击热区在小缩放下不准 | 选错格 | 小缩放下吸附到格中心，或提示放大后再点 |

## 11. 后续版本规划

### 11.1 V1.1 定位增强（建议紧接 MVP）

主题：更快找到位置。

- 跳转：输入行、列
- 邻格步进（移动端方向垫，可收起）
- 下一未完成格
- 按行浏览：当前行置中，上下键换行
- 导出带进度的图片 / 备份文件
- 网格自动建议行列

### 11.2 V1.2 数得更快

主题：从「两点计数」到「一块一块清」。

- 拖动刷选完成
- 同行连续同色提示（基于取色，规则算法）
- 矩形填充标记
- 完成区域统计：本行完成了多少
- 简单分色计数（需用户圈色或点色）

### 11.3 V1.3 作业舒适度

- 暗色模式
- 高对比网格
- 左手模式
- 锁定缩放 / 锁定标记
- PWA 添加到主屏幕
- 图片裁切白边

### 11.4 V2 作品与轻分享

在工具已经粘住用户之后：

- 本地作品文件夹
- 导出 / 导入工程文件（图片 + 网格 + 进度）
- 可选匿名云备份（这时才考虑账号）
- 只读分享链接

仍可不做社区。先让「换手机不丢进度」成立。

### 11.5 V3 智能辅助（谨慎）

只有在网格和定位已经稳定后才做：

- 自动检测图纸网格
- 主颜色聚类与用豆估算
- 拍照校正（透视、白边）

不做：社交 Feed、商城、内容推荐。那些会把产品从工具做成平台，稀释「不再数错格」。

### 11.6 版本原则

后一版本只能强化三个目标中的一个主目标，避免同时铺功能。

```text
MVP   看得清 + 数得准 + 找得到（最小闭环）
V1.1  找得到
V1.2  数得准 / 记得住
V1.3  看得清 / 用得久
V2    不丢失
V3    更省力
```

## 12. 设计与文案要点

### 12.1 语气

短、具体、像旁边有人报数。

推荐：

- 「第 8 行 × 第 12 列」
- 「共 4 格」
- 「再点同一行或同一列」
- 「进度已保存在本机」

避免：

- 「请输入合法参数」
- 「资源加载失败」
- 「单元格索引越界」

### 12.2 视觉基调

- 图纸是主角，UI 是辅助刻度
- 低饱和工具色，高亮用单一强调色
- 完成标记用形状，不用厚重色块
- 移动端字号保证坐标一眼可读

### 12.3 关键文案

| 位置 | 文案 |
| --- | --- |
| 卖点 | 不再数错格 |
| 上传 | 上传拼豆图纸 |
| 空坐标 | 点一个格子，看看你在哪 |
| 数格 | 数格 |
| 测距 | 测距 |
| 完成 | 标为完成 |
| 进度 | 已完成 {done} / {total} |
| 隐私 | 图纸只存在这台设备上 |

## 13. 研发拆分建议（不写实现）

建议按可演示切片开发，每一刀都能给真实用户试用：

| 切片 | 可演示结果 |
| --- | --- |

## 14. 开放问题

评审时需拍板：

1. 数格是否在 MVP 只做同行/同列，还是允许折线连续点选？
2. 修改行列时，清空标记是否可接受？
3. 单设备最多保留多少作品、多大图片？
4. 是否在 MVP 做 PWA？
5. 完成标记的默认视觉：角勾、小点，还是细斜线？

本文档默认：

1. 数格 = 同行或同列两点
2. 改行列 = 确认后清空标记
3. 作品数量先按存储配额限制，不设死数字
4. PWA 不做必达
5. 完成标记 = 格角小勾 / 小点，不遮色

## 15. 结论

拼豆助手 MVP 只做一件事：

> 让用户在真实摆豆时，始终知道自己在哪一格，并能准确数完、记下进度。

第一版的完整闭环是：

**上传图纸 → 对齐网格 → 定位格子 → 数格/测距 → 标记完成 → 本地续拼。**

账号、社区、AI、商城都不进入这个闭环。先把「不再数错格」做成立，产品才有下一阶段。
