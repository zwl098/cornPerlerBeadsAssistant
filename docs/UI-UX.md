## 0. 设计立场

这不是儿童玩具，也不是 CAD。

用户一只手拿豆子、一只手拿手机。界面必须像 **贴在图纸边上的刻度尺**，而不是一个功能很多的 App。

| 关键词 | 怎么落地 | 禁止 |
| --- | --- | --- |
| 像素感 | 方形语言、4–8px 圆角、细网格、等宽坐标数字 | 扫描线、霓虹赛博、8-bit 装饰堆满屏 |
| 工具感 | 画布最大、状态常驻、按钮少而准 | 多面板、多 Tab、专业软件密度 |
| 轻量 | 首页几乎只有一个 CTA；工作区 chrome 尽量薄 | 功能墙、卡片墙、营销模块 |
| 可爱 | 暖色、圆润字重、短句报数、小豆点 Logo | 气球、贴纸风、粗描边粘土风、卡通吉祥物抢图 |

三句话验收：

1. 图纸是不是屏幕上最大、最亮的东西？
2. 用户能不能 1 秒内说出「我在第几行第几列」？
3. 高亮有没有把豆子颜色染脏？

## 0.1 视觉系统

### 气质

**Soft Tool**：照片编辑器的「画布优先」+ 手工产品的「温暖克制」。

参考气质（不是抄界面）：

- 画布优先：VSCO / Procreate 的「图最大、工具贴边」
- 轻工具：Notion 的少按钮、上下文出现
- 可爱克制：无印良品式的圆、暖、干净，而不是儿童 App

### 颜色 Token

高亮不能跟常见豆子色（红、橙、粉、蓝）抢。工作区强调色用 **偏冷的青柠描边 + 黑白双描边**，品牌暖色只用于首页和按钮，不铺到图纸上。

```text
品牌（UI chrome，不铺图纸）
--brand          #E36B4C    珊瑚豆，主 CTA
--brand-pressed  #C95538
--brand-soft     #FFF1EB

页面
--bg             #FFF8F3    首页暖底
--bg-workspace   #F3EEE8    工作区外围
--canvas-well    #D9D3C9    图纸井，中性，让彩色图纸跳出来
--surface        #FFFFFF
--surface-soft   #FFFDFB
--ink            #2B2420
--ink-2          #6B625C
--ink-3          #9A918A
--line           #E8E0D8

功能色（只用于系统反馈，不用于格子高亮填色）
--ok             #2F9E6B
--warn           #C9842A
--danger         #D14B4B

图纸叠加（与品牌色分离）
--focus-stroke-outer  #1A1A1A    当前格外描边
--focus-stroke-inner  #FFFFFF    当前格内描边
--focus-fill          rgba(26,26,26,0.06)
--cross-fill          rgba(26,26,26,0.045)
--count-fill          rgba(46,139,87,0.14)
--count-stroke        #1F7A4D

```

图纸上的颜色一律半透明、细线、双描边。**禁止**用品牌珊瑚大面积罩住格子。

### 字体

| 用途 | 字体 | 原因 |
| --- | --- | --- |
| 标题 / Logo 字 | Outfit 或 Plus Jakarta Sans | 几何、略圆，工具但不冷 |
| 正文 / 按钮 | Plus Jakarta Sans + 系统中文（PingFang SC / Noto Sans SC） | 可读、友好 |
| 坐标 / 进度 / 格数 | JetBrains Mono（tabular nums） | 工具感，数字对齐，数格不易看错 |

字号（Mobile）：

| Token | Size / Line | 用途 |
| --- | --- | --- |
| display | 28 / 34 | 首页标题 |
| title | 17 / 22 Semibold | 顶栏作品名 |
| body | 15 / 22 | 说明 |
| caption | 12 / 16 | 辅助 |
| coord | 15 / 20 Medium Mono | 「第 8 行 × 第 12 列」 |
| count | 20 / 24 Semibold Mono | 「共 4 格」 |

Desktop 标题可到 36–40，坐标保持 15–16，不因屏幕变大而变装饰化。

### 圆角与间距

| Token | 值 | 用途 |
| --- | --- | --- |
| radius-xs | 4 | 格子角标、小勾底 |
| radius-sm | 8 | 按钮、输入、工具格 |
| radius-md | 12 | 卡片、Toast |
| radius-lg | 16 | 底部面板 |
| radius-full | 999 | 进度胶囊 |

间距走 4/8：`4 / 8 / 12 / 16 / 24 / 32 / 48`。

工作区 chrome 用紧凑档：顶栏 48、底栏 64（含安全区外的内容高 56）。

### 图标

统一 **Phosphor Regular，24px，stroke 一致**。不用 Emoji 当图标。

| 语义 | 图标 |
| --- | --- |
| 返回 | `ArrowLeft` |
| 上传 | `UploadSimple` |
| 更多 | `DotsThree` |
| 选择 / 定位 | `NavigationArrow` 或自定义十字准星 |
| 数格 | 自定义：三点横线 + 数字感（或 `Ruler`） |
| 测距 | `Square` 虚线感 / `ArrowsOutCardinal` |
| 完成 | `Check` |
| 撤销 / 重做 | `ArrowUUpLeft` / `ArrowUUpRight` |
| 网格 | `GridFour` |
| 回中 | `Crosshair` |
| 适应屏幕 | `CornersOut` |
| 缩放 | `MagnifyingGlassPlus` / `Minus` |
| 关闭 | `X` |
| 删除 | `Trash` |

工具栏 4 个主模式用「线性图标 + 4 字内标签」。选中态：浅底 + 品牌字色，图标切 `weight="fill"`。

### 动效

工具产品，动效短、不抢手。

- 进入 / 切换：160–220ms，ease-out
- 按压缩放：0.97，120ms，不改布局盒
- 高亮切换：80–120ms（位置必须跟手，不能「飘过去」）
- Loading 旋转是唯一循环动画
- `prefers-reduced-motion`：切瞬变

### 反模式

- 不用粘土风厚边框、大投影
- 不用暗色 IDE 把图纸闷死（MVP 工作区是浅色）
- 不用彩虹装饰像素块当背景
- 颜色不是唯一状态：完成靠小勾，模式靠文字，错误靠文案

## 1. 页面结构

全产品只有 **2 个主页面 + 工作区内面板**。

```text
App
├── HomePage                 首页
│   ├── BrandHeader
│   ├── HeroCTA              上传拼豆图纸
│   ├── RecentRail           最近使用（可空）
│   ├── ExampleRail          示例图纸（2–3 张）
│   └── MiniPitch            三句介绍
│
└── WorkspacePage            图纸工作区 ★
    ├── TopBar
    ├── StatusDock           坐标 / 模式结果
    ├── CanvasStage          图纸井
    │   ├── PatternImage
    │   ├── GridOverlay
    │   ├── CrosshairOverlay 行/列
    │   ├── FocusCell
    │   ├── CountPath / MeasureRect
    │   ├── DoneMarks
    │   └── RulerTicks       行号 / 列号
```

不单独做「作品列表页」为第三主页。首页「最近使用」点「全部」用 **半页 Sheet** 打开本地作品，减少跳转。

### 2.1 组件树（按使用频率）

```text
Foundation
  Color / Type / Space / Radius / Elevation / ZScale

Actions
  ButtonPrimary / ButtonGhost / IconButton / SegmentedMode

Feedback
  Toast / InlineHint / EmptyState / Spinner / Skeleton

Overlay
  CenterModal / BottomSheet / DesktopPopover / ActionMenu

Home
  HeroCTA
  ProjectCard          缩略图 + 进度环/条 + 名称 + 尺寸
  ExampleCard          更轻，角标「示例」
  PitchDots            三词，不是三张大卡

Workspace
  TopBar
  StatusDock
  CanvasStage
  OverlayStack         网格/高亮/标记，同一 transform
  RulerH / RulerV
  ToolDock             Mobile 4 模式
  SideRail             Desktop 信息+工具
  ZoomStrip
  RecenterButton
  GridSheet            行列、边距
  MoreMenu
  CountResultChip

```

### 2.2 关键组件规格

#### ButtonPrimary

- 高 48（Mobile）/ 40（Desktop 次级）
- 圆角 8，填充 `--brand`，白字
- 首页 CTA 可 52 高，全宽（Mobile）或 240 宽（Desktop）
- 按下不位移，只变 `--brand-pressed`

#### IconButton

- 视觉 24，热区 44×44
- 用于返回、更多、撤销、回中

#### SegmentedMode（Desktop 右侧 / 不用于 Mobile 以免占高）

- 四项纵向列表，每项 44 高
- 当前项左侧 3px 品牌条 + 浅底

#### ProjectCard

```text
┌ 4:3 缩略图（格子图） ------┐
│  右下小胶囊  12%            │
└----------------------------┘
小樱的图纸
48 × 48 · 昨天
```

点击整个卡片进入工作区。长按（Mobile）或 hover 出现删除/重命名。

#### StatusDock

常驻，不进 Modal。

| 区 | 内容 | 宽度策略 |
| --- | --- | --- |
| 左 | `第 8 行 × 第 12 列` | 可收缩为 `8 × 12`（375 极窄） |
| 中 | 模式名或「共 4 格」 | 数格/测距时优先显示结果 |
| 右 | `12%` + 回中图标 | 进度永远在 |

数格完成后，中区升级为：

```text
8×12 → 8×15   共 4 格   [标完]
```

375 上「标完」为文字按钮，不是第二行大卡。

#### CanvasStage

唯一允许出现复杂叠加的地方。内部所有层共享一个 `transform`（平移+缩放）。

#### ToolDock（Mobile）

| 槽位 | 默认 | 选中 |
| --- | --- | --- |
| 选择 | 准星线性 | 准星填充 + 品牌色 |
| 数格 | 尺 | 同上 |
| 测距 | 矩形 | 同上 |
| 完成 | 勾 | 同上 |

不要第五个「撤销」占底栏。撤销进 TopBar More，Desktop 放顶栏左侧动作区。

#### ZoomStrip

```text
[ − ]  72%  [ + ]     适应
```

- 不显示过于精确的 `72.4%`
- 档位感：适应 / 100% / 200% 可双击切换，连续缩放仍用捏合
- Desktop 放画布底沿，左对齐，半透明白底，不穿到右侧栏

## 3. UI 层级

### 3.1 Z-Index Scale

禁止 `z-index: 9999`。

| Token | 值 | 层 |
| --- | --- | --- |
| z-canvas | 0 | 图片 |
| z-grid | 1 | 网格 |
| z-done | 2 | 完成勾 |
| z-cross | 3 | 行列弱高亮 |
| z-path | 4 | 数格路径 / 测距框 |
| z-focus | 5 | 当前格 |
| z-ruler | 6 | 行号列号（随画布，但画在视口边） |
| z-chrome | 20 | 顶栏、底栏、侧栏、缩放条 |
| z-status | 21 | StatusDock（可叠在画布顶沿） |
| z-sheet | 30 | 底栏更多、网格面板 |
| z-modal | 40 | 确认框 |
| z-toast | 50 | Toast |
| z-guide | 45 | 首次引导（低于 Toast） |

### 3.2 图纸叠加层级（视觉强度，不是 z）

从弱到强，同时在场时以强者为准：

```text
5 网格线          最弱，只分割
4 完成小勾        弱，不抢色
3 当前行 / 列     中，一条带子
2 数格路径 / 测距框
1 当前格          最强，双描边
0 行号列号当前值   与当前格同级的数字锚点
```

**行列高亮是「带子」不是「整图滤镜」。**  
行带 = 当前行整行高度 × 视口宽，透明度 4.5%。  
列带同理。交叉处不要再叠一层，避免中间变脏。

### 3.3 Chrome 与图纸的空间契约

| 区域 | Mobile 占高 | 是否允许挡图 |
| --- | --- | --- |
| TopBar | 48 + safe | 挡边缘，允许 |
| StatusDock | 36 | 挡顶部 36px，半透明 |
| 列尺 | 20 | 挡顶边，必须 |
| 行尺 | 28 宽 | 挡左侧，必须 |
| ToolDock | 56 + safe | 挡底，允许 |
| ZoomStrip | 36 | 挡底沿，可收 |
| 画布中心 70% | — | **任何常驻 UI 不得进入** |

Sheet 默认半高（45–52%），露出上半图纸做对照。全屏 Modal 只给破坏性确认。

## 4. 操作流程

### 4.1 首次

```text
打开首页
 → 看见「上传拼豆图纸」
 → 选图
 → 进入工作区（图片适应屏幕）
 → 若无网格数据：自动弹出半高 GridSheet
 → 填列 / 行（可锁比例）
 → 对照图纸看网格是否咬住豆子
 → 关掉面板
 → 点一格，看见十字 + 坐标
 → 开始拼
```

引导最多 3 张，可跳过，不锁死画布：

1. 「点一个格子，看你在哪」
2. 「数格：同一行或同一列，点两点」
3. 「摆完就打勾，进度会留下来」

### 4.2 回访

```text
打开首页
 → 最近使用第一张 = 上次作品，带「继续」角标
 → 点入工作区
 → 视口和当前格恢复
 → StatusDock 立刻显示上次坐标
```

### 4.3 工作回路（设计要保护的节奏）

```text
找区域（拖/缩）
 → 点格（确认我在哪）
 → 数格或测距（可选）
 → 低头摆豆
 → 标完成
 → 找下一块
```

每一圈回到「坐标还在」。不允许出现需要关闭弹窗才能看见坐标的设计。

### 4.4 模式切换

底栏 / 侧栏点模式 = 立即切换，无确认。

- 切走数格：保留上次结果展示，直到新的数格开始或点清除
- 切到选择：当前格保留
- 切到完成：当前格保留，下一次点击改的是完成态，不是焦点（见状态机）

## 5. 状态变化

### 5.1 应用级

| 状态 | 界面 |
| --- | --- |
| 冷启动无作品 | 首页，最近使用整段隐藏 |
| 有最近作品 | 首页显示最近轨道 |
| 读取存储中 | 首页卡片 Skeleton |
| 工作中 | 工作区 |
| 存储只读失败 | 工作区可用，顶栏小警告点 |

### 5.2 工作区模式状态机

```text
          ┌─ 点「数格」 ─┐
          ▼               │
Idle/Select ←──────────  Count
   │  ▲                   │
   │  │ 点「选择」         │ 点第二下（同行/列）→ CountResult
   │  └─ 点「测距」 ─→ Measure → 第二下 → MeasureResult
   │  ▲
   └─ 点「完成」 ─→ Mark
```

| 模式 | 点击格子 | Status 主文案 |
| --- | --- | --- |
| 选择 | 设 Focus | `第 8 行 × 第 12 列` |
| 数格（0 点） | 设起点 | `先点起点` |
| 数格（1 点） | 设终点 | 非法则 `请点同一行或同一列` |
| 数格（已有结果） | 新起点 | 结果被替换 |
| 测距（0/1/2） | A / B / 新 A | `再点对角` / `5×4（20 格）` |
| 标记 | 切换该格完成，**同时更新 Focus** | 坐标 + `已标` / `已取消` 不进 Toast（见 Toast 规则） |

### 5.3 当前格视觉状态

| 条件 | 表现 |
| --- | --- |
| 无 Focus | 无十字，Status 为「点一个格子，看看你在哪」 |
| 有 Focus | 双描边 + 行列带 + 尺上号加粗 |
| Focus + 已完成 | 勾仍在，当前格描边压在勾上面 |
| Focus 在视口外 | 回中按钮呼吸一次（仅 1 次，不循环） |

再次点当前格：**保持选中**。不提供点空白取消（避免丢位置）。清除选中只在 More 里，低频。

### 5.4 数格视觉状态

**起点已点：**

- 该格双描边 + 角标「起」
- 同行/列的合法方向上，格子可微微「可点」——不做全行闪烁，避免闪图

**终点合法：**

- 路径内所有格：浅绿 14% 填充 + 1px `--count-stroke`
- 起 / 终角标
- 路径中点浮一层 `共 4`，小胶囊，跟随路径，不进屏幕正中挡视

**终点非法：**

- 终点不收下
- Status 变提醒色字：`数格只能同一行或同一列`
- 可轻震 1 次（支持则做）
- 不弹 Modal

### 5.5 测距视觉状态

- A / B 角标
- 虚线矩形，1.5px `--measure-stroke`
- 矩形外沿中点标注 `5` 和 `4`（宽、高）
- 不填满高饱和色

### 5.6 完成态

单格：

- 右下或左上 **4×4 到 6×6 的小勾**（随缩放：格太小时勾缩到 3px 点）
- 可选 6% 黑遮罩（默认关，显示设置里开）
- **不要**灰阶整格、不要斜线划掉、不要实心绿

批量标记后：路径上的勾依次出现，总时长 < 200ms，不要一格一格庆祝。

### 5.7 控件状态

| 控件 | default | pressed | selected | disabled |
| --- | --- | --- | --- | --- |
| 模式键 | 墨色线性 | 6% 黑底 | 品牌浅底+填充图标 | — |
| 撤销 | 墨色 | 浅底 | — | 40% 透明度，不可点 |
| 主 CTA | 珊瑚 | 深珊瑚 | — | 变灰 + Spinner |
| 输入 | 白底细线 | — | 品牌描边 | 浅底 |

## 6. 空状态

空状态必须带 **一句人话 + 一个动作**，不要空白坑。

| 场景 | 插画 | 文案 | 动作 |
| --- | --- | --- | --- |
| 首页无最近 | 不占大图，直接隐藏该段 | — | — |
| 作品 Sheet 为空 | 小虚线框 | 还没有作品 | 上传拼豆图纸 |
| 工作区无图（异常） | — | 没有图纸 | 回首页上传 |
| 未点格子 | 无插画 | 点一个格子，看看你在哪 | — |
| 数格未开始 | — | 先点起点，再点同一行或列的终点 | — |
| 测距未开始 | — | 点两个角，看这块有多大 | — |
| 完成 0 格 | 进度显示 `0%` | 不单独空态 | — |
| 示例加载失败 | 卡片位保留 | 示例暂时不可用 | 隐藏，不影响上传 |

空状态插画用 **3×3 浅色像素点** 即可，不要大吉祥物。

## 7. Loading

> 超过 300ms 必须有反馈。按钮在异步中禁用。

| 场景 | 表现 | 时长预期 |
| --- | --- | --- |
| 首页读本地列表 | 卡片 Skeleton（缩略图灰块+两行） | < 200ms 可不闪 |
| 选图后解码 | 全屏不打断：工作区先入，画布中心 Spinner +「正在打开图纸」 | 大图 0.5–2s |
| 写入本地 | 无全屏；顶栏小点「已保存」在 600ms 后淡出，失败才 Toast | 防抖 400ms |
| 示例图拉取 | 卡片内 Spinner | — |
| 主 CTA 上传中 | 按钮内 CircleNotch +「正在打开」 | — |

禁止：骨架屏铺满工作区导致用户以为产品坏了。工作区 chrome 先画出来。

Loading 指示器：Phosphor `CircleNotch`，1.5s 一圈，品牌色。不要用豆子弹跳循环动画。

## 8. Error

原则：人话 + 下一步。错误靠近出事地点。

| 场景 | 出现位置 | 文案 | 下一步 |
| --- | --- | --- | --- |
| 非图片 | Toast | 请选一张图片 | 再选 |
| 文件过大 | Modal（因为要解释） | 这张图有点大，换一张 20MB 以内的 | 重选 / 取消 |
| 解码失败 | 工作区空态 | 这张图打不开 | 回首页 |
| 行列非法 | 输入框下 | 至少是 1 | 焦点留在字段 |
| 行列过大 | 输入框下 | 超过 300 格会很卡，确认吗 | 仍可强行 |
| 数格不同行列 | Status 内，不 Toast | 数格只能同一行或同一列，量矩形请用测距 | 继续点 |
| 改行列将清空标记 | Modal | 改格子数量后，完成标记对不上了，要清空标记吗 | 清空并改 / 取消 |
| 保存失败 | Toast + 顶栏警告 | 这步没存上，先别清浏览器数据 | 自动重试 |
| 作品损坏 | Sheet 内 | 这份进度读不出来 | 删除 / 仅打开图片 |
| 无存储 | 首页一条 WarnBar | 关闭页面后进度留不住 | 仍可当次用 |

校验红字用 `--danger`，输入框描边同时变红。不只靠颜色：旁边有文字。

## 9. Toast

### 何时用 Toast

短暂、不挡作业、不需要用户决策。

| 用 | 不用 |
| --- | --- |
| 已保存（仅失败或首次说明） | 每次标记完成 |
| 已撤销 / 已重做 | 切换模式 |
| 请选图片 | 数格结果（结果在 Status） |
| 进度已保存在本机（首次保存后 1 次） | 当前坐标 |

### 规格

```text
┌  icon   进度已保存在这台设备        ┐
└------------------------------------┘
```

- 位置：Mobile 底栏 **上方** 16px（避免被 Home Indicator 和工具栏吃掉）；Desktop 画布底部居中
- 宽：随内容，最大 360
- 圆角 12，白底，细线，轻阴影 `0 8 24 rgba(43,36,32,0.08)`
- 停留 3.2s，可上滑关闭
- 同时最多 1 条，新的替换旧的
- 不出现「×」以免占热区；点一下也可关
- 成功 / 失败靠左侧小图标，不靠整条变绿变红（避免和图纸色打架）

## 10. Modal / Sheet

### 决策

| 交互 | 容器 | 原因 |
| --- | --- | --- |
| 网格校准 | BottomSheet 半高（Desktop 用右侧栏内嵌或居中 400 宽面板） | 必须对照图纸 |
| 更多菜单 | Mobile Action Sheet；Desktop 锚点 Popover | 一过性 |
| 改行列清空标记 | Center Modal | 破坏性，必须看清 |
| 删除作品 | Center Modal | 破坏性 |
| 文件过大 | Center Modal | 需要解释 |
| 首次引导 | 透明点手势 + 底部门票条，**不是**全屏 Modal | 不能挡住图纸 |
| 数格结果 | 不是 Modal | 见 Status |

### Center Modal

```text
      半透明 45% 黑遮罩（不模糊画布，避免看不清颜色）
┌----------------------------┐
│ 改格子数量                  │
│ 完成标记会错位，要清空吗？    │
│                            │
│  [取消]      [清空并修改]    │
└----------------------------┘
```

- 宽 320–360，圆角 16
- 右按钮是破坏性时用 `--danger` 字，不要两个一样重的实心钮
- 点遮罩 = 取消（删除类除外，删除必须点按钮）
- 焦点陷阱，Esc 关闭

### BottomSheet

- 顶上 4×32 拖拽条
- 圆角 16 16 0 0
- 高 45–70%，可拖
- 网格面板字段：列、行、锁定比例、四边微调、显示网格开关
- 常见尺寸以 **文字芯片** 给出：`29×29` `50×50`，不要大图按钮

### 首次引导

三步，底部一条：

```text
1/3  点一个格子，看你在哪     跳过   下一步
```

高亮用圆角矩形框住「示例格」，不要全屏变暗超过 30%，图纸必须仍能看见颜色。

## 11. Mobile 交互

### 11.1 断点

| 宽 | 设备感 | 差异 |
| --- | --- | --- |
| 375 | SE / Mini | 坐标缩为 `8 × 12`；ZoomStrip 可默认收起，双指为主 |
| 390 | 标准 iPhone | 完整 `第 8 行 × 第 12 列` |
| 430 | Plus / Pro Max | Status 可同时显示短结果 + 坐标 |

高度上：底栏 + 安全区 + ZoomStrip 合计约 100–120。画布仍是第一。

### 11.2 手势

| 手势 | 区域 | 行为 |
| --- | --- | --- |
| 单指拖 | 画布 | 平移图纸 |
| 双指捏合 | 画布 | 以双指中心缩放 |
| 单击 | 格子 | 按当前模式命中格 |
| 双击画布 | 空白/图 | 在「适应」与「当前格 200%」间切换 |
| 长按格子 | 可选 P1 | MVP 不做，避免和拖动手势抢 |
| 下拉 Sheet | 面板 | 关闭 |
| 边缘右滑 | 整页 | **不**绑定返回，避免和画布拖动冲突 |
| 返回 | 仅顶栏 ← | 系统手势返回：先关 Sheet/Modal，再回首页 |

工作区 `overflow: hidden` + `touch-action: none` 在画布上，防止整页跟着滚。

### 11.3 热区

- 所有底栏项：宽均分，高 56，图标+文字
- 顶栏图标：44
- 格子在屏幕边长 < 28px 时，单击仍命中该格，但 Toast 一次：「放大一点会更好点」仅首次
- 相邻热区间距 ≥ 8（底栏用均分+内部 padding）

### 11.4 单手

- 主操作在下半屏：模式、标记、缩放
- 坐标在上半屏：低头摆豆时仍能余光看到「8 × 12」
- 回中放 Status 右侧，不用伸到顶角死角
- 不设常驻方向键盘（挡图）。P1 再做可收起的方向垫

### 11.5 横屏 Mobile

MVP 允许横屏：顶栏变 40，底栏保留，左右尺跟着走。不单独做一套。

## 12. Desktop 交互

### 12.1 断点

| 宽 | 布局 |
| --- | --- |
| 1280 | 左画布 + 右栏 280，顶栏动作露出 撤销/重做/网格 |
| 1440 | 右栏 300，ZoomStrip 与画布底对齐 |
| 1920 | 右栏 320，画布吃掉其余宽度；两侧不出现装饰栏 |

< 1024 用 Mobile 结构。1024–1279：仍底栏，右侧不出现，避免画布小于 700。

### 12.2 指针

| 操作 | 行为 |
| --- | --- |
| 滚轮 / 触控板捏合 | 以指针为锚缩放 |
| 按住拖 | 平移（光标 grab / grabbing） |
| 单击格 | 同 Mobile 模式 |
| Hover 格 | 仅 Desktop：该格 1px 白虚线预览 + 旁路小 Tip `8 × 13`，**不**改正式 Focus |
| 双击 | 适应 / 聚焦当前格 |

Hover 绝不作为唯一信息通道。没有 Hover 时（平板）功能完整。

### 12.3 快捷键

与 PRD 一致，并在 More → 快捷键表用一张极简列表（不进首页）。

| 键 | 行为 |
| --- | --- |
| Esc | 关面板；否则回选择模式 |
| ←↑→↓ | 移动当前格，出视口则跟随 |
| Space / X | 切换当前格完成 |
| C | 数格 |
| M | 测距 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| + / - | 缩放 |
| 0 | 适应屏幕 |
| F | 回中当前格 |

方向键移动时，当前格描边立即跳格，不要滑动动画超过 80ms。

### 12.4 右侧栏信息架构（只放「现在需要的」）

顺序固定：

1. 我在哪（坐标，大号等宽）
2. 进度（条 + `128 / 2304`）
3. 模式（四选一）
4. 本次结果（随模式变，空则隐藏整块）
5. 网格摘要（`48×48` + 编辑）

结果块示例（数格）：

```text
终点   第 8 行，第 15 列
```

测距：

```text

到  11 × 16
区域  5 × 4（20 格）
间隔  横 4 · 纵 3

[ 标记此区域完成 ]
```

## 13. 图纸工作区详设计（重点）

### 13.1 画布井

- 背景 `--canvas-well`，像钉板垫在下面
- 图纸 `image-rendering`：放大时偏 `pixelated` / `crisp-edges`，保持像素感
- 网格、高亮、勾、尺 **跟图片锁在同一层变换**
- 缩放锚点 = 手势中心，不是左上角
- 边界阻尼：不能把图拖没；露出最多 24% 井底

### 13.2 网格

- 默认开
- 线宽：屏幕上约 1 物理像素，颜色 `rgba(26,26,26,0.22)`
- 远距离（单格 < 8px）可抽稀画线，但命中仍按精网格
- 与豆子对齐靠 GridSheet 的行列和 inset，不靠「智能吸附」动画

### 13.3 当前格 / 行 / 列 / 号

点击后必须 **同时** 出现 5 件事：

1. **当前格**：内白 2px + 外黑 2px 双描边，填充仅 6% 黑。任何豆子色上都看得清
2. **当前行**：整行弱带，4.5% 黑
3. **当前列**：整列弱带，4.5% 黑
4. **行号**：左侧尺，当前号 Outfit/Mono 加粗，反白小胶囊
5. **列号**：顶尺，同上

```text
        10  11  12  13  14
     ┌─────────────────────
   7 │
   8 │      ┌──┐
     │░░░░░░│■■│░░░░░░░░     ← 行带
     │      └──┘
   9 │       ░
             ░               ← 列带
```

十字不得用半透明品牌橙铺满，否则整图发红。

尺的号码只渲染 **视口内附近**，不要 100 个号全画。当前号永远渲染。

### 13.4 数格「我在数哪一段」

路径必须是一条连续的「糖纸」：

- 浅绿色半透明连成带，两端「起」「终」
- 中间一颗 `共 4` 胶囊，跟手，贴路径内侧
- Status / 右栏同步大号 `共 4 格`
- 非法第二点：路径不连斜线，避免用户以为斜着也算

视觉目标：用户扫一眼就知道「这一小段」，而不是「整张图在发光」。

### 13.5 完成标记

默认方案：**格角小勾**。

| 格的屏幕边长 | 标记 |
| --- | --- |
| ≥ 28px | 5–7px 勾，放在右下，白底 2px 圆角方垫，保证在深色豆子上也能看见 |
| 16–27px | 4px 实心方点在角上 |
| < 16px | 不画勾，该区域用极淡点阵表示「有完成」（可选）；或仅在进度里体现 |

白底小垫（2–3px padding）是为了「看得见」，不是为了盖住整格。勾本身用深墨，不使用大红。

轻微遮罩作为显示设置，默认关。边框方案不作为完成态，以免和当前格描边打架。

### 13.6 回中与迷路恢复

- Status 右侧 `Crosshair`
- 点击：当前格移到画布可视区中心，缩放不变
- 若无当前格：适应全图
- Desktop 另有 `F` 与方向键跟随

### 13.7 工具不挡图的检查表

出视觉稿时对 375 和 1280 各打一帧：

- [ ] 图纸中心 70% 无按钮
- [ ] 数格结果不在正中弹窗
- [ ] 完成勾未盖住格子 90% 面积
- [ ] 行列带叠加后，原色仍可辨
- [ ] 底栏 / 右栏没有第三级菜单常驻

## 18. 设计结论

工作区的视觉中心永远是图纸。  
UI 只做三件事：告诉你在哪、帮你数完、记下你做完的。

若一帧画面里，工具比图纸更抢眼——这帧就失败了。
